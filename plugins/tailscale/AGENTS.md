# tailscale

Usage/privacy: [README.md](README.md).
- `hooks/register.tsx`: each tool's literal `session.start` registration (`inputSchema ... satisfies SchemaFor<McpToolInputs[...]>`, tsc fails when the schema's properties, `required`, `type`/`items` differ from `types/index.d.ts` or a literal union's `enum` is not `allOf` of exactly its members; descriptions are unchecked) and `tool.call` hook, all sharing the top-level `run($, req)` (key, fetch adapter, result); `hooks/schema.ts`: the shared `SchemaFor` and `allOf` (`enum` slots take only `allOf` of exactly the union), a byte-for-byte copy of the template's that `scripts/check-consistency.mjs` enforces, with its type cases in `tests/schema-types.ts`; `hooks/key.ts`: pure key resolution, injected settings read; `hooks/api.ts`: pure `call`, injected fetch, one path validation (`buildUrl`).
- API/host tests: `tests/{tailscale,register}.test.ts`, fake fetch. `tests/paths.ts`: the path tables (`REJECTED_GROUPS`, `ACCEPTED`, `TAILNET_DELETES`, `ALLOWED_DELETES`), each rule pinned once. A new tool adds one `CALLS` entry in `register.test.ts` and its own cases.
- Key: the sensitive `apiKey` option only, no env read. A key that project/local `pluginConfigs` declare for this plugin, or settings that cannot be read, refuse the call (the host does not guarantee otherwise: its docs say only that sensitive options are stored in secure storage). Order: invalid method (write), key, path, forbidden, fetch. Messages name the option, never a value; the key goes only in `Authorization` (`tests/{key,register}.test.ts`: `no output carries the key: success, API error, failed fetch, refusals`).
- Checks: [root commands](../../AGENTS.md#commands).
