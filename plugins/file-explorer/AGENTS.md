# file-explorer

Usage, keys, settings and limits: [README.md](README.md).

## Module map

- `hooks/register.tsx`: every `on(...)`, atom and `$` call. `session.start` registers `/file-explorer`, points the view at the cwd (a reload keeps a view the host still holds), starts the background folder check (`refreshSeconds`, only while the pane is open) and opens the pane unasked when `autoOpen`; `session.end` cancels every timer. A post-result `tool.call` hook reads finished, successful calls of Read, Write, Edit, MultiEdit, NotebookEdit, Grep, Glob and Bash (`touched`): it records the activity, reveals the last read, edited or created file when `follow`, and after a call that may change files re-lists the shown folders whose mtime moved and schedules git (`scheduleGit`, 300 ms debounce, one run at a time with a rerun flag). A Bash `git commit` also marks HEAD's files (`markCommitted`). `classic.SessionStart` adds `.git/index` and `.git/HEAD` to `watchPaths`, `classic.FileChanged` on them schedules git, `classic.CwdChanged` moves an unpinned root, and `prompt.mention` reveals the mentioned file after `next`. The `Pane` render reads the atoms, lays out the rows in view and hands them to the `Client` on `terminal` and `desktop` (plain `Text` rows elsewhere), with Nerd Font icons on `terminal` alone; `ui.message` takes its keys and clicks to `press` and `click`, `ui.scroll` moves the window, and the footer's hotkey Buttons call `press` too. `apply` carries out a move's effect: list a folder, reveal, preview (`showPreview`), open externally (`openExternally`, argv only), mention (`mentionInPrompt`), copy, search (`ensureIndex`: `git ls-files -co --exclude-standard` in a repository, else a bounded walk), refresh, back.
- `hooks/rows.tsx`: the rows' surface module. It paints the segments and posts `{ key }` and `{ click: y }`; it keeps no tree state.
- Pure modules, each with its test: `hooks/explorer.ts` (moves as steps from a view and its rows to the next view and one `Effect`: `navigate`, `revealed`, `collapse`, `settled`, `rowStates`, `treeRows`, `hitRows`), `hooks/tree.ts` (`listingOf`, `sortEntries`, `flatten`, `scrollTop`), `hooks/git.ts` (`parseStatus`, `parseBranch`, `codeOf`, `parseNumstat`, `rollUp`, `totals`), `hooks/activity.ts` (`touchedBy`, `shellEffects`, `commandsOf`, `recorded`, `marksAt`, `nextFlashEnd`), `hooks/search.ts` (`rank`, `score`, `withDirectories`), `hooks/view.ts` (`rowSegments`, `branchSegments`, the palettes), `hooks/icons.ts`, `hooks/open.ts` (`openArgv`, `platformOf`), `hooks/config.ts` (`configOf`), `hooks/paths.ts`.
- `types/index.d.ts`: the state contract (`view`, `dirs`, `git`, `activity`, `tick`), self-contained; the modules alias its types.

## Invariants

- Observation never changes what the host answered: the `tool.call`, `prompt.mention` and classic hooks return `next(e)`'s result as it came, their work runs inside `observe`, and each ends in `.catch((_$, e, next) => next(e))`. `tests/register.test.ts` (`Claude's read is marked and followed into collapsed folders; the tool's result goes on unchanged`, `an @path mention in a prompt reveals the file and is attached as the engine decided`).
- Only finished calls count: a refused or failed call marks nothing. `tests/register.test.ts` (`a write that creates, an edit, and a refused or failed call: only the finished ones are marked`).
- No model calls, no context: nothing here calls `$.model`, appends to the session or answers `prompt.submit`. `a` writes `@path` at the cursor through `$.prompt.fill` and reads no file; a draft that already names it is left alone. `tests/register.test.ts` (`a writes @path at the prompt once, and y copies the relative path; nothing of the file is read`).
- Incremental: only the root and expanded folders are listed, a listing keeps `MAX_ENTRIES` (2,000) with a `… N more` row, the tree flattens to at most `MAX_ROWS`, and the render hands the `Client` only the rows in view. `tests/register.test.ts` (`session start lists the root alone, opens the pane and draws folders first, dotfiles hidden, ignored folders dimmed`, `a folder of 2500 files draws its first 2000 and a row for the rest, and the pane stays within its rows`), `tests/tree.test.ts` (`a listing keeps its first entries and counts the rest`).
- Git and other commands run by argv with no shell; an editor template's placeholders fill whole arguments, a template that is not one simple command or whose program reads its arguments as a command line (`LAUNCHERS`) is refused, and the default opener refuses files it would run. `tests/open.test.ts` (`an editor template fills its placeholders into whole arguments and never reads shell syntax in a name`, `a template that hands its words to a shell or another machine is refused, since the name would be read as code`, `the default opener refuses files it would run rather than show`).
- Git runs as `GIT`: `--no-optional-locks` and `core.fsmonitor=false`, plus `--no-ext-diff --no-textconv` for `diff` and `show`; a commit is a `commit` verb in the command's words, not a pattern over its text. `tests/register.test.ts` (`git runs with no optional locks, no fsmonitor and no external diff or textconv`, `a command that only names git commit marks no commit`).
- Git runs once per burst: changes schedule one `git status` 300 ms after the last, never two at a time. `tests/register.test.ts` (`git index changes reread the status once after a pause; the session end stops every timer`).
- Links are shown with the kind of what they lead to, opened only when the person expands them, and never followed by the search walk. `tests/register.test.ts` (`a link to a folder opens as a folder; a folder that went away leaves the tree on refresh`, `a search outside a repository walks the folders, skipping ignored names and links`).
- Timers end at `session.end`, except on `clear` or `resume`, after which no `session.start` comes; a subagent's `@path` moves nothing. `tests/register.test.ts` (`a /clear keeps the background check running; a subagent mention moves nothing`).
- Animations are one timer per flash end, none with `animations: false`. `tests/register.test.ts` (`a flash ends on its own timer, with no tree or git read again`, `with animations off a touched name never flashes, and the mark stays`).
- Nerd Font icons draw only on `terminal`; other surfaces use their own font and get the Unicode set. `tests/register.test.ts` (`Nerd Font icons draw in the terminal alone; the desktop app, with a font of its own, gets the Unicode set`).
- Paths are compared normalized and under the root by whole parts. `tests/paths.test.ts` (`a path is inside a root only under a whole part of it, never by a shared prefix`).
- Budgets are measured, not assumed: `tests/performance.test.ts` (`flattening 20,000 expanded rows and ranking 50,000 paths stay within their budgets`, `observing Claude's tool calls adds little to each call, and a key on a 2,000-row folder draws quickly`).

## Checks

[Root commands](../../AGENTS.md#commands); type-check with `npm run typecheck -- file-explorer`. `tests/host.ts` is the host fake (`world`, `start`, `pane`, `rows`, `cursor`, `segmentsOf`, `key`): an in-memory file system where `dir/` names a folder and `name -> target` a link, and a scripted git.
