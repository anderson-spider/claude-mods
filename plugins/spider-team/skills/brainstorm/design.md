# Design

Visual decisions are Main's: layout, visual hierarchy, copy users read, interaction flow, colour, type and spacing. Product and scope questions the request leaves open go to the user.

- Settle them before delegating and write them into the brief as concrete specs: structure, states, spacing and type, the components to reuse.
- Show a new screen or flow, or an ambiguous one, to the user as a mockup and take their reaction before any code.
- Review the visual result yourself (screenshot, preview or simulator); a design task is accepted only on what you saw. With no way to see it, ask the user to check it before accepting.
