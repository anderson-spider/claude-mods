# spider-team

Usage/privacy: [README.md](README.md).

- `hooks/register.tsx` is the sole entrypoint. Keep literal agent/tool registration, event matchers, settings/env/state keys and `$` calls there; imported helpers receive injected I/O. Tool schemas satisfy `SchemaFor<McpToolInputs[...]>` against `types/index.d.ts`. Validate native envelopes before narrowing: connected MCP snapshots can contain empty union branches.
- `hooks/roles.ts` owns four exact types, fixed fallbacks, permissions and receipt instructions. Routing changes only model/effort. Readers have no shell/edit tools; developer uses native worktree isolation with merged `worktree.baseRef: "head"`. Permission mode and project instructions inherit. `tests/roles.test.ts` (`four roles keep exact fallbacks permissions isolation and receipt instructions`, `only exact role names and native model families are recognized with effort capped at high`).
- `hooks/effort.ts` owns six automatic profiles and the pin parser. Opus/sonnet/haiku only; cap every origin at high, including xhigh/max pins. Explicit pair/profile pins skip Jev. Assessment failures preserve the exact role fallback even if logging fails. `tests/effort.test.ts` (`one profile table reaches all six profiles regardless of role`, `directives respect escapes quotes inline code and matching fences without rebuilding the task`, `every assessment failure keeps the exact role fallback and logging failure changes nothing`).
- `hooks/jev.ts`, `hooks/key.ts`, `hooks/redact.ts` keep the fixed endpoint, user-environment key boundary, whole-text redaction before clipping, deadline/retry/gate/breaker behavior. `tests/jev.test.ts` (`one deadline covers the call: a fetch that never answers fails with timeout`), `tests/key.test.ts` (`any repository env declaration of JEV_API_KEY is refused`), `tests/redact.test.ts` (`long quoted and bare secret values are consumed completely, including truncated values`).
- `hooks/dispatch.ts` classifies only the exact native ID/type. Every Spider step checks opus/sonnet/haiku and low/medium/high; safe divergent pairs pass. Main passes without an ID; verified external types pass unchanged. Cache misses require one valid row, rejecting unknown Spider types, malformed/missing/duplicate rows and listing errors. Keep the versioned session-only LRU (256 types) separate from telemetry; hits never cache pair authorization, and contradictory evidence invalidates identity. `tests/dispatch.test.ts` (`identity policy covers four native roles and safe divergent pairs without a reservation`, `identity requires one exact valid native row and cache bounds and contradictions fail closed`).
- The guarantee covers the effective native type with stable, non-recycled identity within a session and a trusted hook chain. Rewrites to another type follow that type; hostile plugins, replacement specs, later step hooks and loops skipping this hook are out of scope. Unidentifiable IDs block. Reader restrictions belong to the host-enforced specs. Fake tests do not prove real hook ordering or stable native identity. `tests/register.test.ts`: `native rewrite to external passes and a role swap authorizes only the effective native role`.
- Keep inference independent of calls, parents, snapshots, completion and telemetry retention. Spawn validates local Spider fields without reservations; only its returned native ID establishes call context. Serialize telemetry writes, preserve one dispatch and native errors, and check cancellation before next. Keep at most 256 call/child observation entries in total and 128 compact author/context/report references; remove completed call records after delivery and blocked ones after writing. Finish the current write before eviction; late callbacks cannot recreate dropped entries. Report files remain on disk; expired references never authorize by fallback. `tests/reservations.test.ts` (`full hooks separate same-parent external agents from Spider children before and after spawn with equal concurrent calls`, `cache misses fail closed while verified external and Spider hits survive listing failures and every Spider pair is rechecked`, `identity LRU eviction and incompatible reload are misses and observation eviction never disables the guard`, `bounded call telemetry and compact references expire receipts without deleting files or reviving late callbacks`, `cancellation before dispatch or during persistence prevents final pending writes`).
- Decision paths use a random namespace retained in session state; sessions cannot share caches or overwrite each other's receipts. `tests/register.test.ts`: `separate sessions keep identity caches and decision namespaces apart across registration`.
- Report/diff authorize the caller by its own native type. Context requires the exact spawn link; missing/ambiguous links return fixed BLOCKED errors, including early synchronous reports. Reports belong to their author; never infer role/base/checkout from a parent or pending call. `tests/register.test.ts` (`early synchronous reports block until exact spawn linkage and receipt delivery deduplicates usage`, `developer exact context preserves base checkout and native reconciliation and diff verifies author`, `report and diff refuse unknown ambiguous and expired contexts without fallback`).
- `hooks/report.ts` computes destinations from native session/child IDs, checks symbolic ancestors, bounds the body, verifies developer checkout and returns an indexed receipt. Keep details in the file; the final handback copies the receipt verbatim. Callers cannot choose a destination. `tests/report.test.ts` (`report writes full body once and returns a small receipt with exact section slices`, `report rejects invalid native identity traversal symlinks size and failed writes`, `only completed reviewer reports approve and developer receipts verify checkout context`).
- `hooks/diff.ts` accepts only a finished successful developer report checkout. Fixed Git argv verifies base/repository/branch and covers committed, staged, unstaged and untracked changes. Oversized/truncated output is never presented as complete. `tests/diff.test.ts` (`diff verifies base repository branch and native checkout with fixed argv`, `diff indexes commits staged unstaged and untracked then returns complete per-file pages`, `review refuses running failed partial or removed developer checkouts`).
- `hooks/decisions.ts` explicitly projects telemetry; never serialize task, prompt, report/handback content, paths, native IDs, keys or raw errors. Keep only handback/receipt character counts; deduplicate turn usage. `tests/decisions.test.ts` (`decision projects deep allowlists and records counts without report or handback content`, `failed dispatch has no fabricated observation usage or receipt and hashes are stable`).
- `tests/host.ts` provides fake I/O, session state, native identity and direct hook harnesses. Register fake handlers before the first `$` call. `tests/register.test.ts` (`session start registers four native agents and only report and diff tools`, `native denial and rejected next preserve results without retry or retained tombstones`). Fake coverage is not live inference or quota evidence.
