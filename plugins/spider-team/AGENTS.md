# spider-team

Usage/privacy: [README.md](README.md). Lead workflow: `skills/using-spider-team/SKILL.md`.

- `hooks/register.tsx`: the four literal `$.agent.register` calls in `session.start` and the one `tool.call` hook on `Agent`. It routes only the four exact Spider types (pins, then Jev, then the role default), caps effort at high, refuses bad pins, empty tasks and a developer without merged `worktree.baseRef: "head"`, and on any other failure its `.catch` dispatches the call unchanged. No other hooks, tools, state or files. `tests/register.test.ts` (`session start registers the four native agents and no tools`, `Jev picks the pair for a Spider role, shown in its description, and other agents pass untouched`, `without a key the role default applies and pins skip Jev with effort capped at high`, `invalid pins, empty tasks and a developer without baseRef head are refused before dispatch`, `a routing failure dispatches the call unchanged once`).
- `hooks/roles.ts`: the role table (`SPECS`: prompt, tools, default pair, developer `isolation: "worktree"`). Routing changes only model and effort. Readers have no Write/Edit; reviewer's Bash is limited by its prompt to read-only git. `tests/roles.test.ts` (`four roles keep exact fallbacks permissions and isolation`, `only exact role names are recognized and effort is capped at high`).
- `hooks/effort.ts`: six profiles, the pin parser and selection; assessment failures keep the exact role default. `tests/effort.test.ts` (`one profile table reaches all six profiles regardless of role`, `directives respect escapes quotes inline code and matching fences without rebuilding the task`, `every assessment failure keeps the exact role fallback and logging failure changes nothing`).
- `hooks/jev.ts`, `hooks/key.ts`, `hooks/redact.ts`: fixed endpoint, user-environment key only, whole-text redaction before clipping, deadline/retry/gate/breaker. `tests/jev.test.ts` (`one deadline covers the call: a fetch that never answers fails with timeout`), `tests/key.test.ts` (`any repository env declaration of JEV_API_KEY is refused`), `tests/redact.test.ts` (`long quoted and bare secret values are consumed completely, including truncated values`).
- `tests/host.ts`: fake ports and host (`ports`, `world`, `started`, `call`). Fake coverage is not live routing evidence.
- Checks: [root commands](../../AGENTS.md#commands); type-check with `mise exec -- tsc -p plugins/spider-team/tsconfig.json`.
