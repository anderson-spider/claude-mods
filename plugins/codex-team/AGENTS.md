# codex-team

Usage/privacy: [README.md](README.md). Activation and the lead's workflow: `skills/using-codex-team/SKILL.md`.

- `hooks/register.tsx`: the literal `session.start` registration of `dispatch` (`inputSchema ... satisfies SchemaFor<McpToolInputs[...]>`) and its `tool.call` hook; `teamIo` is the only place with `$` (each `$.env.get` takes a literal name). `hooks/schema.ts`: the type-only `SchemaFor`.
- `hooks/roles.ts`: the role table (`SPECS`: model, effort, whether it writes, instructions), agent names and `codexArgs`. `hooks/report.ts`: the brief and the report path. `hooks/herdr.ts`: `deliver` over an injected runner (team tab or split, reuse, one writer per directory, start, prompt and delivery status). `hooks/team.ts`: `dispatch`, the Herdr check, input checks, the developer's worktree, the decision record. `hooks/decisions.ts`: record shape, path and write.
- Invariants: outside Herdr nothing runs and nothing is written (`tests/team.test.ts`: `outside Herdr the tool says it cannot be used and runs nothing, writes nothing`); an `unknown` prompt is never sent again (`tests/herdr.test.ts`: `a prompt the agent was seen taking is confirmed; refused before writing is not_sent; anything else is unknown and never resent`); one writer per directory (`tests/herdr.test.ts`: `one writer per directory: a second developer in the same worktree is refused, and a developer is not moved to another`); the developer never runs in the repository itself and never gets the git directory as a writable root (`tests/team.test.ts`: `the developer is refused without a worktree of its own`, `the developer works in its worktree and may write only there and in the reports, never in the git directory`); a record never holds the task text (`tests/team.test.ts`: `the decision is logged as unknown before the prompt and with the outcome after, never with the task text`); errors keep only a Herdr code (`tests/herdr.test.ts`: `errors keep only a Herdr code, never the message text`).
- Tests mirror modules; `tests/fake-run.ts` scripts `herdr` and `git`, `tests/host.ts` is the host fake.
- Checks: [root commands](../../AGENTS.md#commands).
