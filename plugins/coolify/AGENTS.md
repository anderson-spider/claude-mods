# coolify

Usage/privacy: [README.md](README.md).
- `hooks/register.tsx`: each tool's literal `session.start` registration (`inputSchema ... satisfies SchemaFor<McpToolInputs[...]>`, tsc fails when the schema's properties, `required`, `type`/`items` differ from `types/index.d.ts` or a literal union's `enum` is not `allOf` of exactly its members; descriptions are unchecked) and `tool.call` hook, all sharing the top-level `run($, req, options)` (access, fetch adapter, result). The write hook denies a bad method, then a `DELETE` whose `confirm` does not repeat the path's last segment, before any option is read. `hooks/schema.ts`: the shared `SchemaFor` and `allOf`, a byte-for-byte copy of the template's that `scripts/check-consistency.mjs` enforces, with its type cases in `tests/schema-types.ts`; `hooks/access.ts`: pure `url` and `apiKey` resolution, injected settings read; `hooks/api.ts`: pure `call`, injected fetch, one path validation (`buildUrl`), `forbidden`, `deleteTarget` and read redaction.
- API/host tests: `tests/{coolify,access,register}.test.ts`, fake fetch. `tests/paths.ts`: the path tables (`REJECTED_GROUPS`, `ACCEPTED`, `FORBIDDEN_POSTS`, `DELETES`), each rule pinned once. A new tool adds one `CALLS` entry in `register.test.ts` and its own cases.
- Options: `url` (https origin, optionally ending in `/api/v1`) and the sensitive `apiKey`, no env read. Either one declared by project/local `pluginConfigs` for this plugin with a value the user source does not declare (`repoChose`), or settings that cannot be read, refuse the call: a repository-chosen `url` would receive the user's token. A value equal to the user's passes, since a session opened in the home folder reads `~/.claude/settings.json` as its project source. Order: invalid method or unconfirmed delete (write), key, url, settings, path, forbidden, fetch. Messages name the option, never a value; the key goes only in `Authorization` (`tests/{access,register}.test.ts`).
- API reference: `openapi.yaml` at the root of `coollabsio/coolify`. Secret fields are snake_case, so the redaction matches names, plus `value`/`real_value` of objects with a string `key` (environment variables).
- Checks: [root commands](../../AGENTS.md#commands).
