# gitlab

Usage/privacy: [README.md](README.md).
- `hooks/register.tsx`: each tool's literal `session.start` registration (`inputSchema ... satisfies SchemaFor<McpToolInputs[...]>`) and `tool.call` hook (with a `.catch` that answers an error), all sharing the top-level `run($, tool, input, option)`: remote, token, API, then the tool. `hooks/schema.ts`: `SchemaFor` (strings, literal unions, integers, booleans, string arrays) and `allOf`, which fails tsc when an `enum` misses a member of its union. Action unions live in `types/index.d.ts`.
- `hooks/remote.ts`: `parseRemote`, `locate` (origin, else the first remote), `currentBranch`, over injected git. `hooks/tokens.ts`: the `tokens` option as `host=token` pairs, `resolveToken` and the refusal texts. `hooks/api.ts`: `gitlab(fetch, host, project, token)`; every path is built from checked ids and the encoded project, never from the model. `hooks/context.ts`: `Ctx`, input checks, `mrIid` (the current branch's open MR without an iid), `userIds` (`@me`), `clip`.
- Tools, one module each: `hooks/mr.ts`, `hooks/comments.ts`, `hooks/pipelines.ts`, `hooks/joblog.ts`. Merging and deleting comments are not offered (`tests/register.test.ts`: `session start registers the four tools and no merge action`; `tests/mr.test.ts`: `approve, unapprove and rebase call their endpoints, and merge is not an action`).
- Token: one per host, sent only to the remote's host in `PRIVATE-TOKEN`; refused when the repository's settings declare `tokens` or cannot be read; never in an output (`tests/register.test.ts`: `the remote picks the host and its own token: the work host for one repository, gitlab.com for another`, `API errors and failed calls are error results naming the project, and no output carries a token`). A remote URL is never echoed (`tests/remote.test.ts`: `locate uses origin, else the first remote, and never echoes an unreadable remote URL`).
- Tests mirror modules; `tests/fake-api.ts` is the fake API for tool tests and `tests/host.ts` the host fake (`world`, `started`).
- Checks: [root commands](../../AGENTS.md#commands); type-check with `mise exec -- tsc -p plugins/gitlab/tsconfig.json`.
