# comfyui-local

Usage/privacy: [README.md](README.md).
- `hooks/register.tsx`: each tool's literal `session.start` registration (`inputSchema ... satisfies SchemaFor<McpToolInputs[...]>`: tsc fails when the schema's properties, `required`, `type`/`items` differ from `types/index.d.ts` or a literal union's `enum` is not `allOf` of exactly its members; descriptions are unchecked) and its `tool.call` hook, all sharing the top-level `run($, options, work)` (access, then the host's fetch, process and file check handed to the tool). `hooks/schema.ts`: the shared `SchemaFor` and `allOf`, a byte-for-byte copy of the template's that `scripts/check-consistency.mjs` enforces, with its type cases in `tests/schema-types.ts`. `hooks/access.ts`: pure `url` resolution, injected settings read (http or https origin, the repository-chosen check as in coolify). `hooks/api.ts`: one pure function per tool over an injected `Fetch` (`$.http.fetch`, text only) and `Run` (`$.process.run`, curl for the multipart upload and the binary downloads); the answer is capped at `LIMIT` characters.
- Endpoints: ComfyUI `server.py` (`/system_stats`, `/object_info`, `/models`, `/models/{folder}`, `/prompt`, `/history/{id}`, `/queue`, `/interrupt`, `/upload/image`, `/view`, `/templates/index.json`, `/templates/{name}.json`, `/api/workflow_templates`, `/api/workflow_templates/{pack}/{name}.json`), its `app/user_manager.py` (`GET /api/userdata?dir=workflows&recurse=true&split=false&full_info=true`, `GET` and `POST /api/userdata/{file}` with `file` the whole `workflows/<path>.json` URL-encoded, slashes included) and ComfyUI-Manager 4 `comfyui_manager/glob/manager_server.py` with `data_models/generated_models.py` (`/v2/customnode/installed`, `/v2/customnode/import_fail_info_bulk`, `/v2/manager/version`, `/v2/manager/reboot`, `/v2/manager/queue/{task,start,status,history}`; `QueueTaskItem` kinds and params). `POST /api/userdata/{file}` overwrites unless the query says `overwrite=false`, so `saveWorkflow` always sends it; only UI format (`nodes` and `links` arrays) is saved, since an API-format file in `workflows/` breaks the frontend's list. The reboot answers 400 to a form content type (`common/manager_security.py` `reject_simple_form_post`) and 403 below `security_level` middle, so it goes as JSON `{}`; it re-executes the process, so the connection usually drops (a 502 to 504 behind a proxy), but `restartServer` counts the restart only once a poll of `/system_stats` found the server down: the first poll comes at `RESTART_FIRST_POLL_MS` after a dropped connection or a gateway error, else at `RESTART_POLL_MS`; a server that still answers `RESTART_STILL_UP_MS` after the reboot was sent never restarted, while an answer before that may be the old process shutting down. `getWorkflow` writes a workflow past `LIMIT`, or any with `file`, to a local file through the injected `WriteText` (`$.fs.write`), and `saveWorkflow` reads one back with `file` through `ReadText` (`$.fs.read`). `workflowFile` refuses `%`, since `user_manager.py` unquotes the name again after the route did. It waits on an injected `Clock` whose `sleep` is `$.process.run(['sleep', ...])` (PowerShell `Start-Sleep` where that fails): a `$` call does not use up the hook's 10 s budget, `$.clock.sleep` would. The worker keys a registry pack by its registry id and a git-cloned one by its folder with `is_unknown` (`do_update`, `do_uninstall` there), so `managerTask` resolves the pack against the installed list first. `$.process.run` gets `timeoutMs` (`UPLOAD_MS`, `DOWNLOAD_MS`) since its default is 30 s, and curl's `--max-time` sits just under it; text fields go as `--form-string`, which never reads a file. Manager 4 has no local catalog route: `manager_search_packs` queries the public registry `https://api.comfy.org/nodes?search=`. Templates are UI-format JSON, so `get_template` hands them over as reference and never submits them.
- Commands: `commands/*.md`, adapted from Comfy-Org/comfy-skills `claude-code/commands/` (`commands/LICENSE.comfy-skills.txt`): keep the authoring rule of the original (steer the approach, discover specifics with the tools). The commands name core node classes (CheckpointLoaderSimple, KSampler, ...) and model families (SDXL, Wan, ...) as examples only, never a model file. No Comfy Cloud step; search-templates only notes which templates need a partner API node, it runs none.
- Tests mirror modules: `tests/access.test.ts`, `tests/api.test.ts` (a fake server per test, routes as `METHOD path`), `tests/register.test.ts` (`session start registers every tool, each with a described input`, `a call without the url option is refused before any request`, `restart_server waits through the host process, never the hook clock, and refuses with jobs queued`). `tests/host.ts`: the host fake (`world`, `started`) with fetch, process, file, settings and clock handlers.
- Checks: [root commands](../../AGENTS.md#commands).
