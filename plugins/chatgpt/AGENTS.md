# chatgpt

Setup, use, privacy or live browser checks: read [README.md](README.md). Editing backend choice or registration: read `tests/backends.test.ts` and `tests/register.test.ts` for the pinned behavior. Editing prompts: `tests/prompts.test.ts` pins the send boundaries, character budget and image boundaries, and the prompt texts byte for byte; `tests/tool-schemas.test.ts` pins the tool and command wording and the input schemas. A new page script gets its fake branch in `tests/fake-page.ts` (`scriptKind`, `fakePage`).

- `scripts.ts`: page scripts/selectors; `terminal-browser.ts`: injected `Browser` adapter; `mcp-browser.ts`: MCP calls/upload/polling; `mcp-backend.ts`: `mcpBackend(spec)`, which builds an MCP backend's `Browser` and `stays` from one spec (name, server, hint, tab-id prefix, listing tools, tab protocol); `chrome-browser.ts`, `builtin-browser.ts`: those two specs; `browsers.ts`: chooser.
- `backends.ts`: the single `BACKENDS` list (the order the plugin tries them), `OWN_CALLS` and the pure `ownCallAllowed`: what `tool.check` allows, only the plugin's own browser calls on chatgpt.com, never the model's. Every backend has a `hint`: the chooser's setup advice and the "not ready" advice (`prepare`, which takes the names injected as `backends`, since `backends.ts` imports its module) are built from the list, never written by hand. A new MCP backend is a spec in `backends.ts` (in a module of its own when its tab protocol is long, like the two there) and its row in `tests/backends.test.ts`, which pins its hint, the allow and deny cases and the advice over the real list; `tests/register.test.ts` pins the shipped texts byte for byte (`NO_BROWSER`, `NOT_READY_ADVICE`), so they change with a new backend. `README.md` lists the backends by hand.
- `register.tsx`: MCP calls, named `$.tool.register`/`$.command.register` calls, and the literal `on('tool.check', ...)` that passes the call's origin, tool, input and the plugin's tab to `ownCallAllowed` (`tests/register.test.ts` pins that wiring). `backends.ts` takes no `$`.
- `tool-schemas.ts`: schemas/jobs/commands; `prompts.ts`: ask/image descriptions and prompt section; `ask.ts`, `image.ts`, `conversation.ts`: flows; `runner.ts`: queue/jobs; `output.ts`: `$TMPDIR/chatgpt/` files.

Checks: `claude plugin validate plugins/chatgpt`; `claude plugin test plugins/chatgpt`; `node scripts/check-consistency.mjs`.
